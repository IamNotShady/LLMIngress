// SELF-HOSTED AI GATEWAY

One gateway for every AI agent.One gateway for every AI agent.One gateway for every AI agent.

LLMIngress sits between your AI agents and your model providers. Point Codex, Claude Code, Cursor — or any agent that speaks an OpenAI- or Anthropic-compatible API — at a single endpoint. It picks the right model for each request, falls back when a provider fails, and meters every token. On your machine, with your keys.

01 CAPABILITIES

Everything between the agent and the model.

01 ONE_ENDPOINT

Unified ingress

OpenAI- and Anthropic-compatible APIs from one port. Chat, responses, messages, and model discovery — every agent speaks to the same door, each with its own scoped key.

spec: /v1/chat/completions · /v1/messages · /v1/responses · /v1/models

02 VIRTUAL_MODELS

Stable names, routed models

Agents ask for code-fast. A route policy — fixed order, cost-first, or load balance — resolves the real model, and capability pre-checks validate context length and tool use before dispatch. No LLM judge in the loop.

spec: fixed · cost_first · load_balance

03 FALLBACK_CHAIN

Failure is a routing event

429s, 5xx, timeouts — the request moves to the next model in the chain, up to five deep, across providers and local models. Your agent never sees the outage.

spec: triggers before first streamed chunk

04 COST_LEDGER

Every token accounted

Tokens, cost, and latency per agent, per virtual model, per provider — actual cost where the provider reports it, estimated where it doesn't.

spec: cache + reasoning tokens tracked separately

05 HARD_LIMITS

Budgets and rate limits

Per-agent budgets from hourly to monthly, plus RPM / TPM / concurrency and per-request token caps. A runaway loop stops at the gateway instead of running up cost.

spec: budget · rpm · tpm · tokens · concurrency

06 SELF_HOSTED

Self-hosted, single-user

Runs on your laptop or server, binds to localhost by default. Provider keys encrypted at rest; prompts never written to operational logs.

spec: Node + Postgres · one compose file

02 SETUP

Three steps, one endpoint.

1

Connect your providers

Paste API keys for OpenAI, Anthropic, Google, OpenRouter — connect a personal subscription, or point at local Ollama. Keys are encrypted at rest and never shown again.

2

Define virtual models

Name a policy like code-fast or deep-reasoning; set its model scope, cost preference, and a fallback chain.

3

Point your agents at the gateway

Each agent gets the base URL, its own llmi_ key, and a budget. Done — every request now routes, falls back, and gets metered.

# Claude Code → LLMIngress
export ANTHROPIC_BASE_URL="http://localhost:4000"
export ANTHROPIC_AUTH_TOKEN="llmi_cc_4f8a…"

claude   # model: code-fast (virtual)
# Codex — ~/.codex/config.toml
model = "code-fast"
model_provider = "llmingress"

[model_providers.llmingress]
name     = "LLMIngress"
base_url = "http://localhost:4000/v1"
env_key  = "LLMINGRESS_API_KEY"  # llmi_cx_9b2e…
curl http://localhost:4000/v1/chat/completions \
  -H "Authorization: Bearer llmi_dev_a1c3…" \
  -d '{ "model": "code-fast",
        "messages": [{ "role": "user",
                       "content": "…" }] }'

04 DEPLOY

Runs where you work.

# clone, generate ENCRYPTION_KEY into .env, then run
git clone https://github.com/IamNotShady/LLMIngress.git
cd LLMIngress
./scripts/deploy.sh

Gateway :4000 · Console :3000 · Postgres :55432 · bound to 127.0.0.1 by default

RECOMMENDED

Docker Compose

Postgres bundled, migrations run on first boot, random ENCRYPTION_KEY via ./scripts/deploy.sh. Nothing listens publicly until you change a host.

FOR HACKING

Local Node

pnpm install && ./init.sh against your own Postgres. The full dev loop for contributing.

ALWAYS ON

Server / VPS

Same compose file. Override .env ENCRYPTION_KEY if you want, point CONSOLE_PUBLISH_HOST at your network, keep the Gateway and Postgres private.

05 FAQ

Fair questions.

The things developers actually check before running someone else’s gateway.

Is it open source? +

Yes — Apache-2.0, self-hosted, built for a single user. No SaaS, no telemetry, no account.

Which agents can connect? +

Anything that lets you set an OpenAI-compatible base URL — Codex, Cursor, OpenCode, and GitHub Copilot among them. Claude Code connects natively through the Anthropic-compatible /v1/messages endpoint.

Are my prompts stored? +

No — the gateway records metadata only (model, tokens, cost, latency). Prompts, successful responses, and tool arguments are never written to operational logs.

Do my provider keys ever leave my machine? +

No. Agents only ever hold their own llmi_ gateway keys. Provider keys stay on your deployment, encrypted at rest.

What does it cost to run? +

The software is free. You pay providers directly, at their prices — and the Usage page shows what each agent actually spent, per provider and per model.
